# IPL Cricket Analytics

## Project Overview

This project is focused on analysing Indian Premier League (IPL) cricket data to discover patterns, trends and insights across multiple seasons.

The project will use Python, SQL and data analysis techniques to explore IPL matches, teams, players and ball-by-ball performance data.

## Business Question

How can historical IPL data be analysed to identify important trends in team performance, player performance and match outcomes across different IPL seasons?

## Dataset

The IPL dataset contains five related tables and covers 19 seasons of IPL cricket.

The project will use the approved data source provided for this course. Raw source data will not be committed to this GitHub repository.

The dataset will be organised into:

- Raw data
- Processed data
- Match information
- Player and team information
- Analytical datasets
